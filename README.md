# WaveEase
Catch the wave, teach with ease!

## What is it?
Teachers spend hours creating materials for their classes; WaveEase can shave that time down to minutes. WaveEase is a teacher-assistant platform aimed at simplifying and supplementing classroom management. It utilizes Artificial Intelligence to streamline everyday needs for teachers. It includes a lesson planner, rubric maker, quiz creator,  email framer, grading assistant, and text leveler. 

## Key Features
**Lesson Planner** - Creates a complete lesson with a timeline and resources.

**Rubric** - Creates a rubric tailored to any assignment. Weighs different categories and analyzes learning targets.

**Quiz Maker** - Designs a quiz on any subject. The tool leverages the provided items to create progressively difficult questions.

**Email Framer** - Crafts professional emails for communication with students, parents, and administrators.

**Grading Assistant** - Reviews and scores students' work. Provides specific feedback that helps students improve.

**Text Leveler** - Converts any text into versions appropriate for their grade level. Preserves the core meaning while adjusting vocabulary or language to match the grade selected.

## Tech Stack
**Python** - Programming language

**Django** - Framework for building the backend

**OpenAI API** - Uses GPT-5o-mini to generate content

## Set Up
"Get your API key from the OpenAI platform"
1. Clone the repository
2. Create virtual environment: python3 -m venv venv
3. Activate virtual environment: source venv/bin/activate
4. Install dependencies: pip3 install -r requirements.txt
5. Create an '.env' file in the project root and add: OPENAI_API_KEY="your_api_key_here"
6. Run server: python3 manage.py runserver
7. Open browser: go to localhost URL
